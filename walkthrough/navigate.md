## Getting around

Drag to pan and scroll to zoom.

| Key | Action |
| --- | --- |
| `H` | Show or hide the cell hierarchy |
| `/` | Find a cell or text label by name |
| `M` | Switch between Pan and Measure |
| `Esc` | Clear the search, rulers or cell outlines |
| `[` `]` | Step through DRC markers |
| `Ctrl+G` | Go to a coordinate |

Run **GDS Lens: Show Keyboard Shortcuts** to see this list in the viewer. Its
**Customize...** button opens Keyboard Shortcuts, where you can change any of
these keys.

Click a shape to see its layer, cell path, size and area. Click the same spot
again for the shape underneath.

In the hierarchy, click a row to frame that cell and outline every placement
of it. Click **⤒** on a row to show that cell as the new top.

Right-click the layout and choose **Copy coordinate** to copy the point under
the pointer.
